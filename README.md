# 💻 Cincinnati Union Terminal

Starter files for an independent CSS assignment. The HTML for a two-page guide to
**Cincinnati Union Terminal**, the 1933 Art Deco train station that is now Cincinnati Museum
Center, is already written. You will add a responsive image and a captioned video, then write
all of the CSS: fonts, a type scale, spacing, a background-image hero, and a floated photo.

There is no follow-along video for this assignment. You build it on your own, and a walkthrough
video unlocks in Canvas after you submit.

> [!NOTE]
> `.editorconfig`, `.gitattributes`, `.gitignore`, `.noai`, and the `.github` and `.idea`
> folders are setup files that keep assignments consistent. Leave them alone. `index.html`,
> `visit.html`, `css/styles.css`, and the `images` and `media` folders are your starter files.

## 📂 Where Your Files Go

This time the files are already named and in the right places. **Do not rename or move them**,
because the pages, images, video, and stylesheet all link to each other by these exact names:

```
index.html
visit.html
css/
    styles.css
images/
media/
```

Write all of your CSS in `css/styles.css`. Both pages already link to it. Inside the HTML,
change only the spots marked with a `TODO` comment.

## 🤖 AI Policy

Work on this assignment must be your own. Do not use AI coding assistants — including
GitHub Copilot, Cursor, ChatGPT, Claude, or JetBrains AI Assistant — to generate,
complete, or rewrite your code.

You should be able to explain any line of your submission. You may be asked to do so.

This repo includes a `.noai` file, which disables JetBrains AI Assistant for the project
in IDEs like WebStorm. Leave it in place. It is a reminder of the policy above, not a
substitute for it — following the policy is still your responsibility.

> [!NOTE]
> The `.noai` file does **not** turn off WebStorm's local Full Line code completion. Turn that
> off yourself as part of the [one-time setup](.github/WEBSTORM_SETUP.md) (step 5).

> [!CAUTION]
> Late or missing submissions are graded on what is in the pull request at the deadline, so push your final commits
> before you submit.
